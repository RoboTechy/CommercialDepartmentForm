سامانه مدیریت فرم واحد بازرگانی و انبار
راهنمای استخراج و اجرای پروژه (نسخه داکریزه شده)
=============================================

دوست عزیز سلام،
فایلی که دانلود کرده‌اید (commercial-portal-source.zip) یک فایل فشرده (ZIP) است که کل پروژه (تمامی کدهای React، وب‌سرور Nginx، فایل‌های Dockerfile و docker-compose) در داخل آن قرار دارد.

مرحله ۱: استخراج فایل‌ها از حالت فشرده (Unzip)
---------------------------------------------
- در ویندوز:
  روی فایل دانلود شده راست‌کلیک کرده و گزینه "Extract All..." یا "استخراج همه" را انتخاب کنید.
- در مک یا لینوکس:
  روی فایل دو بار کلیک کرده یا در ترمینال دستور unzip را اجرا کنید.

بعد از استخراج، پوشه‌ای با تمام فایل‌ها شامل:
- فایل‌های داکر: Dockerfile, docker-compose.yml, nginx.conf, DOCKER_GUIDE.md
- پوشه src (تمام کدهای برنامه، فرم‌ها، استور و ساختار دیتابیس)
- فایل‌های package.json, index.html, vite.config.ts و ...
مشاهده خواهید کرد.

روش اول (سریع‌ترین و تمیزترین): اجرا با داکر (Docker Compose)
-------------------------------------------------------------
کافیست در پوشه پروژه ترمینال را باز کرده و یک دستور بزنید:

   docker compose up -d --build

سپس در مرورگر باز کنید:
👉 http://localhost:8080

روش دوم: اجرا به صورت محلی با Node.js
-------------------------------------------------------------
۱. برنامه Node.js را نصب داشته باشید.
۲. در پوشه پروژه، ترمینال (یا CMD) را باز کنید و بنویسید:
   npm install
۳. سپس بنویسید:
   npm run dev
۴. در مرورگر به آدرس http://localhost:3000 بروید.

موفق باشید.
